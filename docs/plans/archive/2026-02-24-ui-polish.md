# UI Polish Pass: Implementation Plan

**Goal:** Eliminate wasted space across Dashboard, Remote, Hardening, and Scheduler pages by fixing empty states, adding side-by-side layouts, and improving directional guidance.

**Architecture:** Add a shared `.two-col-row` CSS class for consistent side-by-side layouts with `align-self: start` to prevent height-matching stretch. Fix per-page issues: drop oversized min-heights, improve empty-state content, remove unnecessary card wrappers.

**Tech Stack:** CSS (styles.css), Rust/Leptos components (hardener-ui)

Key changes:
- Removed redundant `flex-direction: row` (default)

- Removed `display: flex; flex-direction: column` from children (Card already handles this)
- Removed redundant `.schedule-section, .notification-section { flex: 1 }` (parent `> *` already sets it)
- Removed `margin-top: auto` from `.form-actions` (was pinning buttons to bottom of stretched card, no longer needed since cards size to content)
